# Ideias para Brainstore

## Habilidade Proposta
- Nome sugerido: "vendas-report"
- Objetivo: Gerar relatórios de vendas a partir de planilhas Excel ou CSV

## Contexto do Usuário
- O usuário precisa de relatórios mensais de vendas
- Usa arquivos em CSV ou XLSX
- Quer gráficos de barras e tabelas resumidas
- Precisa exportar para PDF ou HTML

## Variáveis Sem Definição
- Formato de saída: PDF ou HTML?
- Período: mensal, trimestral, anual?
- Métricas: apenas vendas totais, ou incluir CAC/LTV?

## Fluxo de Trabalho Sugerido
1. Carregar arquivo (CSV/XLSX)
2. Limpar dados (remover duplicatas, tratar nulos)
3. Calcular métricas agregadas
4. Gerar visualizações (gráfico de barras, tabela)
5. Exportar para formato escolhido
