# BritLearn App — English Learning Platform

AI-powered English learning app with **8 modules** (Listen, Pronunciation, Write, Read, Conversation, Grammar, MemHack, Numbers) and **5 languages**.

## Architecture

- `backend/` — FastAPI API (`engine.py` + `main.py`)
- `frontend/` — SPA without build (pure HTML/CSS/JS)
- `frontend/i18n.js` — Internationalization (EN/ES/FR/IT/DE)

## How to Run

The backend serves both the API and the frontend (SPA) on the same port.

```bash
cd backend
pip install -r requirements.txt
python3 -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Open **http://localhost:8000** in your browser (Chrome recommended for voice).

> The frontend uses relative URLs (`/api/...`), so no separate server or CORS needed.

## Demo Mode vs. AI Mode

### OpenRouter (Recommended — text-only)
```bash
export OPENROUTER_API_KEY=sk-or-...
export OPENAI_MODEL=openai/gpt-4o-mini
# optional: export OPENROUTER_REFERER=... OPENROUTER_TITLE="BritLearn App"
```

> **AI voice is generated by Edge TTS** (neural voices, no key needed),
> much better than browser's default voice. Default voice `en-US-GuyNeural`;
> change with `export EDGE_TTS_VOICE=en-US-GuyNeural`. If Edge TTS fails,
> the frontend uses `speechSynthesis` as fallback.

### OpenAI (Optional, with TTS)
```bash
export OPENAI_API_KEY=sk-...
export OPENAI_MODEL=gpt-4o-mini
```

Uses `tts-1` for AI voice when available.

### No Key (Demo Mode)
Heuristic correction + browser voice. Works for testing the UI.

In all cases, user speech can be transcribed via Whisper at `/api/stt` (optional).

## Internationalization (i18n)

The app supports 5 languages via `frontend/i18n.js`:

- HTML uses `data-i18n` attributes for text translation
- `data-i18n-placeholder` for input placeholders
- `data-i18n-title` for tooltips
- Translation function `t(key, replacements)` with variable support

## Authentication

- JWT-based session (session cookie)
- HttpOnly cookies with SameSite=Lax
- HMAC-SHA256 signed tokens
- Bcrypt password hashing
- User management (create/list users)
